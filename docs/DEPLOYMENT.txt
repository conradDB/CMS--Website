CMS WEBSITE — DEPLOYMENT

Extract this archive into your web server's chosen site directory. Keep index.html, styles.css, app.js, experience.js, content.js, web.config and assets/ together. No npm install, database, API key or AI-platform hosting is needed on the production server.

IIS: web.config includes the index.html default document and WebP/WOFF2 mappings. Check inherited server configuration in staging. Apache/nginx/other static hosts can ignore web.config. HTTPS is recommended for production and enables normal clipboard behaviour.

CONTENT AND INTEGRATION NOTES
- Original supplied CMS eco / Wilson artwork is included and integrated without alteration.
- Wilson is a clearly labelled scripted demonstration, not a live AI integration.
- Enquiries are prepared in the visitor's email application, not submitted to a backend. The visitor must review and send.
- PAIA opens the existing CMS-hosted PDF; no local PDF copy was available.
- Interface examples and the procedural 3D artwork are illustrative. All visual assets are local.
- Preserve or redirect old product URLs when replacing the current site.

Verified with Chromium using a static HTTP server. The organisation’s production web server has not been tested.
